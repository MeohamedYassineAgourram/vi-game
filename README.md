# 🎂 Viviane's Journey — Birthday Adventure

Bienvenue sur **Viviane's Journey**. Cette application est une aventure interactive créée pour célébrer l'anniversaire de Viviane.

Elle contient :

- Une landing page cinématique et illustrée.
- Cinq mondes interactifs présentés sous forme de cartes flottantes.
- Des mini-jeux à compléter pour débloquer la suite du voyage.
- Une surprise finale avec un gâteau d'anniversaire à 20 bougies.

## 🚀 Lancement rapide

Ouvrez un terminal à la racine de ce dossier puis lancez les deux commandes suivantes :

```bash
rm -rf .next
npm run dev
```

Ensuite, ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🛑 Arrêter le projet

Dans le terminal qui exécute l'application, utilisez :

```bash
Ctrl + C
```

## 🧭 Parcours

1. Acceptez le défi depuis la landing page.
2. Choisissez le monde disponible dans les cartes flottantes.
3. Terminez les cinq mini-jeux.
4. Découvrez la surprise finale pour Viviane.
