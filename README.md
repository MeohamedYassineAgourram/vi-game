## 🚀 Lancement rapide

Ouvrez un terminal à la racine de ce dossier puis lancez les deux commandes suivantes :

```bash
rm -rf .next
npm run dev
```

Ensuite, ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🛑 Arrêter le projet

Dans le terminal qui exécute l'application, utilisez :

```bash
Ctrl + C
```
